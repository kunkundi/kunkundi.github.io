签名范围Signing scope

CrossDesk 使用 SignPath.io 为本仓库构建的官方 Windows 发布包提供代码签名。CrossDesk uses SignPath.io to sign official Windows releases built from this repository.

数字签名帮助您确认发布者身份，并验证文件在签名后未被修改。Digital signatures help you confirm the publisher and verify that files have not been modified after signing.
