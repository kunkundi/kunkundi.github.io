CrossDesk 代码签名政策 CrossDesk Code Signing Policy

最后更新：2026 年 8 月 8 日 Last updated: August 8, 2026

CrossDesk 官方 Windows 发布包使用数字签名，帮助用户确认发布者身份并验证文件在签名后未被修改。

签名服务与证书

CrossDesk 使用 SignPath.io 为本项目构建的官方 Windows 发布包提供免费代码签名，证书由 SignPath Foundation 提供。
