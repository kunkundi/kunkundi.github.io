开始第一次远程连接Start your first connection

  1. 在被控电脑上安装并运行 CrossDesk，等待连接服务器，查看本机设备 ID。Install and run CrossDesk on the remote computer. Wait for it to connect to the server, then find its device ID.
  2. 在控制端打开 CrossDesk 或 Web 客户端，输入被控电脑的 ID。Open CrossDesk or the Web client on your controlling device and enter the remote computer’s ID.
  3. 输入被控端的连接密码，建立远程会话。使用自托管时，两端需启用同一套服务器配置。Enter the remote device’s connection password to start a session. For self-hosting, configure both clients to use the same server.

下载常见问题Download questions

下载后为什么无法安装？Why won’t the package install?

先核对操作系统与 CPU 架构。iOS ZIP 需要自行签名；macOS 的远控权限需要按系统提示授予。Check your operating system and CPU architecture. The iOS ZIP needs signing; macOS remote control permissions must be granted in system settings.

Linux 标准版和虚拟桌面版怎么选？Which Linux package should I choose?

操作当前已有桌面时选标准版。没有桌面环境，或希望创建独立 Xfce 桌面时，选择虚拟桌面版。Choose Standard to control an existing desktop. Choose Virtual Desktop when you need a separate Xfce session or have no desktop environment.

只用浏览器可以连接吗？Can I connect using only a browser?

控制端可以使用 Web 客户端；被控电脑仍需运行 CrossDesk。The controlling device can use the Web client. The remote computer still needs to run CrossDesk.
